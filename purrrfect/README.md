# Purrrfect Cats — Luxury Adoption Experience

## Site architecture

- `index.html` — luxury homepage and entry point to the matching experience.
- `match/index.html` — **Find Your Purrrfect Match** questionnaire and matching results.
- `cats/` — one folder per individual cat. Every cat has an independent profile URL, gallery, personality, age, needs, adoption status and match guidance.
- `cats/_template/` — reusable profile template for future cats.
- `assets/images/` — site-wide images, logos and visual assets.
- `assets/css/` — shared styling.
- `assets/js/` — matching logic and reusable interactions.
- `data/` — structured cat personality/matching data.

## Cat profile standard

Every cat profile should include:

1. Name and age
2. Breed/colour/sex
3. Individual hero photography
4. Private gallery section using that cat's own photos
5. Personality and habits
6. Ideal home/household
7. Energy level and interaction needs
8. Children/dog/other-cat compatibility
9. Grooming, enrichment and care notes
10. Why this cat may suit particular parents
11. Adoption status
12. Individual enquiry/application CTA
13. Link back to the matching tool

## Matching experience

Visitors can describe their household and habits first. The site compares their answers with each cat's profile and returns a small set of suitable cats with a compatibility explanation.

The result is a **potential compatibility indicator**, not an automatic adoption approval. The breeder makes the final suitability decision after reviewing the application and speaking with the family.

## Important content rule

All ages, personalities, compatibility claims, health information, pedigree information and adoption statuses must be replaced with verified information supplied by Purrrfect Cats before launch. Demo names/photos/content are placeholders only.
